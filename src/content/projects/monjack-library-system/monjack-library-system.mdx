図書館管理システム「文籍 (MonJack)」は、長年にわたり学校や海外日本人学校、研究室などで利用していただいています。

費用面で電算化をためらう現場でも導入のきっかけになるよう、坂田算浩さんと一緒に開発してきたシステムです。
